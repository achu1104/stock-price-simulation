
# Stock Price Simulation and Risk Analysis

## Project Overview
This project uses Python to simulate historical stock prices,
estimate annual return and volatility, and forecast 1,000
possible stock-price paths for the next year.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib

## Features
- Historical stock-price simulation
- 20-day and 50-day moving averages
- Annual return and volatility estimation
- Monte Carlo simulation with 1,000 paths
- 5th, 50th, and 95th percentile analysis
- 95% Value-at-Risk (VaR)
- Fan chart and final-price histogram

## Installation
Install the required libraries:

pip install -r requirements.txt

## Run the Project
python stock_simulation.py

## Output
The program displays a fan chart and a histogram
and saves the visualization as stock_forecast.png.

## Disclaimer
This is an educational simulation using synthetic
stock prices, not financial advice.
